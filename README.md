# PBL2: Landline Telephone Directory Management System
This repository contains the source code for Project-Based Learning 2 (PBL2) at Da Nang University of Science and Technology (DUT). The project simulates the landline telephone directory management system using object-oriented programming in C++.
# Key feature:
Subscriber management: add, update, delete, search, and display
Province-based directory organization
Separate data files for each province or city
Subscriber statistics by region
Duplicate phone number detection and removal
File-based data storage
Object-oriented design using C++
