# PBL2 - Landline Phonebook Management

Cau truc:
- ThueBaoCoDinh.h/.cpp: lop thue bao co dinh.
- ThanhPho.h/.cpp: quan ly file du lieu cua mot tinh.
- QuanLyDanhBa.h/.cpp: quan ly cac tinh/thanh pho va cac chuc nang menu.
- main.cpp: chuong trinh chinh.
Bien dich bang g++:
g++ -std=c++17 -Wall -Wextra main.cpp ThueBaoCoDinh.cpp ThanhPho.cpp QuanLyDanhBa.cpp -o PBL2

Chay tren Windows PowerShell:
.\PBL2.exe
Moi tinh se tao mot file .dat, vi du: DaNang.dat, HaNoi.dat.
Dinh dang moi dong:
Ten don vi|Dia chi|So dien thoai
